# Website fonts

These are the font files used by the supplied Command Line reference, downloaded on 2026-10-12 from its [theme assets](https://commandline.microsoft.com/wp-content/themes/command-line/assets/fonts/).

- PP Neue Montreal: Book (400), Medium (500), Bold (700), and Book Italic (400), OpenType.
- Cascadia Code: normal and italic variable fonts, weights 200–700, WOFF2.

The font-face declarations preserve the reference weights and styles. Font ownership and licensing remain with their respective owners.
